# Domain Model

Domain entities include users, sessions, roles, products, pricing policies, carts, orders, invoices, payments, refunds, wallets, ledger accounts/entries, panels, routing decisions, provisioning operations, subscriptions, notifications, alerts, tickets, commissions, settlements, audits, feature flags, files, and backups. State machines are explicit for orders, payments, provisioning, subscriptions, refunds, tickets, settlements, and broadcasts.
