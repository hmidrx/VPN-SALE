# Runbook: corrupted-migration

## Scope
Milestone 7-A1 operational response for corrupted-migration. Do not expose secrets or customer data in incident notes.

## Steps
1. Confirm environment and release metadata.
2. Check readiness, alerts and recent deployments.
3. Preserve evidence and assign an incident owner.
4. Apply the least-risk mitigation from staging-tested procedures.
5. Record residual risk, rollback notes and follow-up actions.

## DR values
Proposed RPO/RTO are documented separately from verified values. Verified values remain `NOT_VERIFIED` until a timed restore drill proves them.
