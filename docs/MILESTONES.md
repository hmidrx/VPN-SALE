# Milestones

Detailed milestone matrix is included below.

## Milestone 0
- Scope: Architecture and repository foundation
- Out-of-scope: later milestones and production secrets.
- Dependencies: prior milestones.
- Data model changes: documented migrations only.
- API changes: versioned and tested.
- UI changes: RTL/accessibility reviewed.
- Tests: unit/integration/contract/e2e as applicable.
- Security review: required.
- Observability: logs/metrics/audits updated.
- Acceptance criteria: documented checks pass; for Milestone 0, GitHub Actions and Codespaces provide authoritative verification when local environments lack registries or Docker.
- Rollback: reversible deploy and migration plan.
